This folder contains games created using the library curses, which allows the creation of animated text-based games inside of python, allowing the simulation of motion, adding new depth to the games.

The first game is a recreation of the popular game Bob the Robber, where the goal is to get through the level without getting touched by the lasers. You have to go through the rooms, picking locks on doors and avoiding traps to get to the end of the level. Keep in mind, it is pretty hard.

The second game is Christmas Battle, a holiday themed fighter where you can pick one of four characters, and customized battle settings to fight and try to beat a bot.

The third game is a simple infinite runner. How long can you survive?

The fourth game is a recreation of the popular Google Snake game where you have to make the snake eat all the mice without running into itself or the walls. The catch is, the snake gets bigger with every mouse it eats.
